# CIS 344 Project 1 - Online Career Coaching System

## Project Description

This project is an Online Career Coaching System developed for CIS 344. 
The purpose of the system is to manage clients, career coaches, coaching 
sessions, payments, and reviews.

The database was designed and implemented using MySQL Workbench.

## Main Entities

- Client
- Career Coach
- Coaching Session
- Payment
- Review

## Project Files

- `Project1_Brea_Elaine.mwb` - MySQL Workbench database model
- `Project1_Brea_Elaine.sql` - SQL database structure and sample data
- `Project 1 CIS 344.pdf` - Final project report
- Word document - Editable version of the final project report

## Database Features

The database includes:

- Primary and foreign keys
- Relationships between tables
- Client and career coach information
- Coaching session scheduling
- Payment records
- Client reviews and ratings
- Sample data for testing

- MySQL Workbench
